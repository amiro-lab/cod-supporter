# 캡처 가이드

이 폴더에 MW4 스크린샷을 넣어 주세요. 사이트의 건스미스 스탯 시뮬레이터와 반동 분석 데이터의 원본이 됩니다.

## 1단계 — 파일럿 (6~8장)

`captures/pilot/` 폴더에 넣어 주세요. 파일명은 아무거나 괜찮습니다.

| # | 찍을 화면 | 확인하려는 것 |
|---|---|---|
| 1 | 무기 하나(예: M4)의 건스미스 화면, **부착물 없는 기본 상태** | 스탯이 숫자로 나오는지, 막대로만 나오는지 |
| 2 | 1번 화면에서 "상세 스탯" 같은 토글·탭이 있으면 그 화면 | 숨겨진 상세 수치가 있는지 |
| 3 | 같은 무기에서 부착물 하나에 커서를 올린 상태 (총구 등) | 부착물 변화량이 어떻게 표시되는지 |
| 4 | 3번과 **같은 부착물**을 **다른 무기**에 올린 상태 | 부착물 효과가 무기마다 다른지 |
| 5 | 슬롯 하나의 부착물 목록 전체 | 부착물 이름, 해금 조건 |
| 6 | 사격장에서 벽에 조준을 고정하고, 반동을 잡지 않은 채 한 탄창 연사한 직후 | 탄흔이 남는지, 반동 패턴을 읽을 수 있는지 |
| 7 | (가능하면) 6번 장면을 10초 정도 녹화한 영상 | 영상 기반 자동 분석이 가능한지 |

## 촬영 조건 (가능한 범위에서)

- 모든 캡처를 **같은 해상도**로 찍어 주세요. 가능하면 1920×1080 이상, HDR은 OFF.
- **게임 언어**는 평소 쓰시는 그대로 두세요. 한국어 UI면 공식 한국어 명칭을 바로 쓸 수 있어서 오히려 좋습니다.
- 반동 테스트 조건:
  - FOV 값을 고정하고 기록해 두세요.
  - 조준보정(에임 어시스트)은 OFF.
  - 서서 정조준(ADS) 상태에서 찍어 주세요.
  - 입력 장치(마우스/패드)를 함께 메모해 주세요.
- 게임 패치 버전을 알면 `captures/pilot/notes.txt`에 적어 주세요. 설정 화면이나 런처에 표시됩니다.

## 2단계 — 본 촬영

파일럿 결과를 보고 무기별로 찍을 목록을 정리해 드립니다. 폴더는 무기별로 나누기만 하면 됩니다(예: `captures/m4/`). 파일명은 따로 정할 필요 없습니다. 화면 내용을 보고 직접 분류합니다.
